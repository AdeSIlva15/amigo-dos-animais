\# Amigo dos Animais



Projeto front-end desenvolvido para uma ONG fictícia chamada Amigo dos Animais. A aplicação apresenta informações sobre projetos da organização e disponibiliza um formulário de cadastro.



\## Tecnologias utilizadas



\- HTML5

\- CSS3

\- JavaScript

\- DOM

\- LocalStorage

\- Vite

\- Git e GitHub



\## Estrutura do projeto



\- `html/` - páginas da aplicação

\- `css/` - estilos visuais

\- `js/` - módulos e funcionalidades JavaScript

\- `imagens/` - recursos visuais

\- `vite.config.js` - configuração do build com Vite



\## Instalação e execução



Para instalar as dependências do projeto:



npm install



Para executar o ambiente de desenvolvimento:



npm run dev



Para gerar a versão de produção:



npm run build



Para visualizar a versão de produção:



npm run preview



\## Versionamento



O projeto utiliza Git para controle de versão e GitHub para hospedagem do repositório.



A organização das branches segue o padrão GitFlow:



\- `main` - versão estável do projeto

\- `develop` - desenvolvimento contínuo

\- `feature/` - desenvolvimento de novas funcionalidades



As mensagens de commit seguem o padrão Conventional Commits.



\## Build e otimização



O projeto utiliza Vite para geração da build de produção e minificação dos arquivos HTML, CSS e JavaScript.



A imagem principal também foi comprimida para reduzir o tamanho do arquivo e melhorar o carregamento da aplicação.



\## Acessibilidade



Foram aplicadas melhorias de acessibilidade, incluindo elementos semânticos, navegação por teclado, indicadores de foco, atributos ARIA e link para acesso direto ao conteúdo principal.
